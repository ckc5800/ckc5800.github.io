Synthetic Data Generation with Latent Diffusion 인피닉

2023.09 ~ 2023.12 · 생성 모델 기반 국방 데이터 확보 연구

문제
국방 도메인은 보안 제약으로 학습 데이터 수집이 어렵고, GAN은 모드 붕괴로 대안이 못 됨
해결
웹에서 모은 전차 이미지 7,586장으로 Latent Diffusion을 학습해 새 전차 이미지를 생성하고 실제 데이터와 비교
우수 논문상한국국방기술학회 2023
2편관련 논문
Latent Diffusion Generative Model PyTorch Data Augmentation

상세 기록배경 · 구현 · 성과 · 생성 결과

절 이동배경구현성과생성 결과

배경

국방 도메인 AI 모델 개발의 학습 데이터 부족 (보안 제약으로 수집 어려움).GAN 모드 붕괴 문제 및 범용 생성 모델의 도메인 불일치.

구현

진행: 선행 연구를 인수인계받아 Latent Diffusion 기반 전차 이미지 생성 실험을 이어서 진행.

검증 및 평가: 웹에서 모은 전차 이미지 7,586장으로 학습해 새 전차 이미지를 생성하고 실제 데이터와 비교 — 상당 부분 유사하나 아직 실제 데이터를 대체할 수준은 아님을 확인. 후속으로 UNet 대신 UNet++·UNet3+ 구조 적용을 제시.

  • 추가 논문: "GAN을 활용한 데이터 생성 연구 동향" (한국항공우주학회 2023)
