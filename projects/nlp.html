NLP Text Summarization System 인피닉

2024.01 ~ 2024.07 · 사내 지식 관리 · 요약 시스템 개발

문제
휴가·부재 후 복귀한 직원이 단체방에 쌓인 업무 대화를 따라잡는 데 시간이 오래 걸림
해결
대화는 BART, 문서는 T5로 나눠 개발하고 사내 메신저에 탑재
2초대업무 대화 요약
약 300명사내 메신저 전사 탑재
BART T5 Hugging Face NLP PyTorch

상세 기록배경 · 구현 · 성과

절 이동배경구현성과

배경

휴가나 부재 후 복귀한 직원이 단체방에 쌓인 업무 대화를 따라잡는 데 오랜 시간이 걸린다는 문제에서 출발.사내 메신저에 넣을 한국어 요약 모델 개발이 목표.

구현

모델 설계: 대화 요약은 BART, 문서 요약은 T5로 나눠 개발.후속으로 사전 학습 표현을 훼손하지 않는 R3F 정규화 파인튜닝을 설계하고 적용을 계획.

연구 계획: 한국어 대화-요약 쌍 데이터 수집·전처리와 한국어 임베딩 모델 선택을 1단계로 잡고, ROUGE 점수와 사내 인원 휴먼 평가를 평가 지표로 설정.

성과

  • 사내 메신저에 요약 기능을 붙여 전 직원(약 300명)이 쓰는 서비스에 실제 적용
  • 긴 사내 공지 문서를 한 줄 요약으로 압축, 실제 업무 대화는 2초대에 요약
  • 카카오톡 대화 요약 기능과 나란히 비교해 유사한 품질의 요약을 확인한 데모 수행
  • STT 결과 텍스트를 활용한 자연어 처리 기능 개발과 전처리·평가 환경 구축도 함께 수행
