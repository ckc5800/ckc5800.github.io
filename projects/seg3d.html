3D Semantic Segmentation Research 인피닉

2022.08 ~ 2022.12 · 센서 퓨전 기반 자율주행 연구 — 논문 작성·발표 · 코드 작성 (기여도 25%)

문제
2D 세그멘테이션만으로는 자율주행에 필요한 거리·높이 정보를 얻을 수 없음
해결
LiDAR와 카메라를 융합하는 Trans-Unet 설계.Transformer의 장거리 의존성에 U-Net의 다중 스케일을 결합
31.94%2D MIoU · 단일 모달 2배
2편논문 (제1저자)
2건등록 특허 (제1발명자)
Trans-Unet Sensor Fusion PyTorch LiDAR Computer Vision Autonomous Driving

상세 기록배경 · 구현 · 성과

절 이동배경구현성과

배경

자율주행 환경 인식에 3D 거리/높이 정보 필수.기존 2D 세그멘테이션의 한계로 인한 센서 퓨전 필요.

구현

모델 아키텍처: Trans-Unet (Transformer + U-Net 하이브리드) 설계로 LiDAR 포인트 클라우드 + 카메라 이미지 효과적 퓨전.Transformer 장거리 의존성 + U-Net 다중 스케일 피처 추출 결합.

연구 기여: 논문 2편 제1저자 게재 (한국자동차공학회 2022.11, 2023.04) 및 특허 2건 등록 (제1발명자).

성과

  • 논문 2편 게재 (제1저자, 한국자동차공학회 추계학술대회 2022.11 · 한국자동차공학회논문집 2023.04) — 2D MIoU 31.94%로 단일 모달의 약 2배, 3D MIoU 17.12%
